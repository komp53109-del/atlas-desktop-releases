# Atlas for Windows — releases

This repository only holds installers and update files for the Atlas Windows app. It contains no
source code.

- **Install:** download `Atlas-Setup-X.Y.Z.exe` from the latest release and run it.
- **Updates:** an installed copy checks this repository on its own and updates in the background.

Installers are not code signed yet. On first install Windows may show "Windows protected your PC":
choose **More info → Run anyway**.

Releases are published automatically by CI; please do not upload files here by hand.
